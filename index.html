VoicePad

Саундпад с озвучкой текста нейросетью: пишете фразу — она звучит в игре через микрофон.

Скачать установщик Без установки (.exe)
Windows 10/11. Windows может показать предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».

Как начать

  1. Запустите VoicePad. Если нет виртуального микрофона, программа предложит установить его одной кнопкой (бесплатный драйвер VB-CABLE). Windows попросит подтвердить установку.
  2. Во вкладке «Настройки» вставьте API-ключ с fish.audio.
  3. В игре или Discord выберите микрофоном «CABLE Output».
